# Code of Conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcome newcomers, accept feedback gracefully, and keep discussion about the work. Harassment, insults, and
publishing other people's private information are not acceptable.

To report a concern, open a private security advisory on this repository or contact the maintainers through the repository owner's GitHub
profile. Reports are handled privately.
